## О проекте

Данный проект систематически объединяет ключевые области медицинской генетики, геномики, метаболических заболеваний, пренатальной диагностики, генной терапии и эпигенетической регуляции, охватывая **131 важнейший клинический навык**.

**Целевая аудитория**: Врачи-генетики, студенты-медики, генетические консультанты, исследователи в области персонализированной медицины, медицинский персонал пренатальной диагностики

**Справочный учебник**: *Медицинская Генетика*, 8-е издание

**⚠️ Риск ⚠️**: Данный набор навыков может формировать рекомендации, оказывающие значительное влияние на клиническую, репродуктивную, судебно-медицинскую практику или генную терапию. При использовании исключительно в качестве профессиональной консультации это может нести риски.
**Меры по снижению риска**: Используйте все выходные данные только в образовательных целях или для проверки клиницистом. Прежде чем принимать решения о диагностике, лечении, беременности, судебно-медицинской экспертизе, установлении отцовства, генетическом тестировании или генной терапии, убедитесь в наличии квалифицированного медицинского, генетического или юридического контроля.
**⚠️ Риск ⚠️**: Анализ генетических случаев может затрагивать конфиденциальную личную или семейную информацию о здоровье.
**Меры по снижению риска**: Перед раскрытием или обработкой идентифицируемой генетической, репродуктивной информации или семейного анамнеза необходимо применить соответствующие меры контроля согласия, конфиденциальности и локальных соглашений.

### Стратегии вопросов

#### 1. Понимание концепций
Вопрос:
```bash
Что такое закон равновесия Харди — Вайнберга?
```
Ответ:
```bash
## Равновесие Харди — Вайнберга

Равновесие Харди — Вайнберга — это фундаментальный принцип популяционной генетики, описывающий, что в идеальных условиях (случайное скрещивание, отсутствие мутаций, отбора, миграции, бесконечно большая популяция) частоты аллелей и генотипов остаются постоянными из поколения в поколение.

### Основная формула
Для биаллельного аутосомного локуса (A и a):
- p = частота A, q = частота a
- p + q = 1
- Частоты генотипов: p²(AA) + 2pq(Aa) + q²(aa) = 1

### Клиническое применение
- **Оценка частоты носительства**: Для АР-заболеваний, где известна частота заболеваемости q², частота носителей 2pq ≈ 2q
- **Контроль качества**: Проверка соответствия данных генотипирования ЗХВ
- **Выявление стратификации популяции**: Отклонение от ЗХВ может указывать на стратификацию популяции или селективное давление
```

#### 2. Клинический разбор案例
Вопрос:
```bash
Фенотипически нормальная супружеская пара уже имеет одного ребенка с аутосомно-рецессивным заболеванием. Каков риск повторения для следующего ребенка? Если у них уже есть двое здоровых детей, как изменится риск?
```
Ответ:
```bash
## Анализ генетического консультирования

### Исходные данные
- Оба родителя фенотипически нормальны → Оба являются **носителями** (Aa × Aa)
- Уже есть один больной ребенок → Тип наследования подтвержден

### Оценка риска рецидива

| Ситуация | Риск рецидива | Объяснение |
|----------|--------------|------------|
| Базовый риск на каждую беременность | 25% (1/4) | Менделевское соотношение |
| После одного больного ребенка | 25% (1/4) | Независимое событие; риск на беременность не меняется |
| После двух здоровых детей | 25% (1/4) | Независимое событие; не влияет на последующий риск |
| Индивидуальный риск после байесовского обновления | Снижается | Это пересмотр *вероятности того, что пара является носителями* |

### Ключевые моменты консультирования
1. **Каждая беременность независима**: Предыдущие результаты не влияют на последующий риск
2. **Подтверждение носительства**: Рекомендуется генетическое тестирование обоих родителей
3. **Пренатальная диагностика**: Доступна пренатальная генетическая диагностика при будущих беременностях
4. **Преимплантационная генетическая диагностика (ПГД)**: Доступный вариант

> ⚠️ Следует различать «пересмотр вероятности носительства после рождения здоровых детей» (байесовский) и «риск рецидива на каждую беременность» (независимое событие) — это разные концепции.
```

#### 3. Экзаменационные вопросы
Вопрос:
```bash
Какой кариотип наиболее часто встречается при синдроме Дауна?
A. 47,XX,+21
B. 46,XX,der(14;21)(q10;q10),+21
C. 47,XX,+21/46,XX
D. 46,XX,inv(21)
```
Ответ:
```bash
**Ответ: A. 47,XX,+21**

**Обоснование:**
- **Свободная трисомия (стандартный тип)** : 47,XX,+21 или 47,XY,+21 — составляет **92-95%** случаев синдрома Дауна
- **Транслокационный тип**: напр. 46,XX,der(14;21)(q10;q10),+21 — составляет **2-4%**
- **Мозаичный тип**: напр. 47,XX,+21/46,XX — составляет **2-3%**

**Клинические аспекты:**
| Тип кариотипа | Доля | Риск рецидива |
|--------------|------|---------------|
| Свободная трисомия | 92-95% | Коррелирует с возрастом матери |
| Транслокационный | 2-4% | Коррелирует с родителем-носителем (если мать — носитель сбалансированной транслокации, риск ~10-15%) |
| Мозаичный | 2-3% | Зависит от доли аномальных клеток; риск рецидива обычно низкий |

> Примечание: Свободная трисомия является наиболее распространенным кариотипом при синдроме Дауна и положительно коррелирует с возрастом матери.
```
